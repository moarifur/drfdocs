# UpdatingModels

## Reshaping the Project

At this stage, the basic `Movie` model with only three fields (`name`, `description`, `active`) is too limited. To build a proper IMDB clone, the models need to be expanded and restructured.

**Changes made:**
- Rename `Movie` → `WatchList` (a more general name that can include TV shows, podcasts, Web series)
- Rename `name` → `title`
- Add a `created` timestamp
- Add a `StreamPlatform` model to represent Netflix, Prime Video, Disney+, etc.
- Delete the old database and rebuild from scratch

---

## WatchList Model

```python
from django.db import models

class WatchList(models.Model):
    title       = models.CharField(max_length=50)
    storyline   = models.CharField(max_length=200)
    active      = models.BooleanField(default=True)
    created     = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title
```

`auto_now_add=True` automatically records the time when the object is first created.

---

## StreamPlatform Model

```python
class StreamPlatform(models.Model):
    name    = models.CharField(max_length=30)
    about   = models.CharField(max_length=150)
    website = models.URLField(max_length=100)

    def __str__(self):
        return self.name
```

This model stores streaming platforms: Netflix, Amazon Prime, Disney+, YouTube, etc.

---

## Why WatchList Instead of Movie?

A movie implies only theatrical releases. The `WatchList` model is deliberately generic:
- A Netflix original series → `WatchList`
- A YouTube show → `WatchList`
- A Spotify podcast → `WatchList`
- A cinema movie → `WatchList`

## Rebuild Steps

After changing models:

```bash
# Stop the server
# Delete db.sqlite3 (or reset migrations)
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
