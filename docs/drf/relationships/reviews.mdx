# Reviews

## Goal

Add a `Review` feature to the IMDB clone so users can rate and review each movie or show.

- One `WatchList` can have many `Review` objects
- One `Review` belongs to exactly one `WatchList`
- Rating is constrained between 1 and 5

---

## Review Model

```python
from django.db import models
from django.core.validators import MinValueValidator, MaxValueValidator

class Review(models.Model):
    rating      = models.PositiveIntegerField(
                    validators=[MinValueValidator(1), MaxValueValidator(5)]
                  )
    description = models.CharField(max_length=200, null=True)
    watchlist   = models.ForeignKey(
                    WatchList,
                    on_delete=models.CASCADE,
                    related_name='reviews'
                  )
    active      = models.BooleanField(default=True)
    created     = models.DateTimeField(auto_now_add=True)
    updated     = models.DateTimeField(auto_now=True)

    def __str__(self):
        return f"{self.rating} | {self.watchlist.title}"
```

Key field notes:
- `MinValueValidator` / `MaxValueValidator` — enforce that rating is 1–5 at the database level.
- `related_name='reviews'` — access all reviews for a movie with `watchlist.reviews.all()`.
- `auto_now_add=True` — set once when created, never updated.
- `auto_now=True` on `updated` — refreshes on every save.

## Connecting Review to WatchList Serializer

Add the nested `reviews` field to `WatchListSerializer`:

```python
class ReviewSerializer(serializers.ModelSerializer):
    class Meta:
        model  = Review
        fields = '__all__'

class WatchListSerializer(serializers.ModelSerializer):
    reviews = ReviewSerializer(many=True, read_only=True)

    class Meta:
        model  = WatchList
        fields = '__all__'
```

`read_only=True` — reviews are added through the `ReviewSerializer`, not through the `WatchListSerializer`.
