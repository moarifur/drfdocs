# Requests

## Adding POST Support

Extend the `movie_list` view to accept POST requests:

```python
@api_view(['GET', 'POST'])
def movie_list(request):
    if request.method == 'GET':
        movies = Movie.objects.all()
        serializer = MovieSerializer(movies, many=True)
        return Response(serializer.data)

    if request.method == 'POST':
        serializer = MovieSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        else:
            return Response(serializer.errors)
```

When a POST request comes in, `request.data` contains the JSON body sent by the client. The serializer validates it; if valid, `.save()` is called, which triggers the `create()` method on the serializer.

---

## The `create()` Method

DRF's base `Serializer` class does not know how to save data automatically. You must define `create()`:

```python
class MovieSerializer(serializers.Serializer):
    ...

    def create(self, validated_data):
        return Movie.objects.create(**validated_data)
```

`validated_data` is the cleaned dictionary of fields that passed validation.

## Adding PUT Support

For updating an individual item, extend `movie_detail`:

```python
@api_view(['GET', 'PUT', 'DELETE'])
def movie_detail(request, pk):
    movie = Movie.objects.get(pk=pk)

    if request.method == 'GET':
        serializer = MovieSerializer(movie)
        return Response(serializer.data)

    if request.method == 'PUT':
        serializer = MovieSerializer(movie, data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        else:
            return Response(serializer.errors)

    if request.method == 'DELETE':
        movie.delete()
        return Response(status=status.HTTP_204_NO_CONTENT)
```

When calling `MovieSerializer(movie, data=request.data)`, you pass the **existing instance** as the first argument and the **new data** as `data=`. This tells DRF to call `update()` instead of `create()` when `.save()` is called.

---

## The `update()` Method

```python
def update(self, instance, validated_data):
    instance.name        = validated_data.get('name', instance.name)
    instance.description = validated_data.get('description', instance.description)
    instance.active      = validated_data.get('active', instance.active)
    instance.save()
    return instance
```

`instance` holds the old values; `validated_data` holds the new values sent by the client.

---

## PUT vs PATCH

| Method | Behaviour |
|--------|-----------|
| `PUT` | Updates all fields — the entire resource is rewritten |
| `PATCH` | Partial update — only specified fields are updated, the rest remain unchanged |

## DELETE

A DELETE request removes the object and should return no body:

```python
if request.method == 'DELETE':
    movie.delete()
    return Response(status=status.HTTP_204_NO_CONTENT)
```

Import `status` at the top:

```python
from rest_framework import status
```
