# Validation

## Overview

DRF supports three levels of validation in serializers, all triggered when `serializer.is_valid()` is called:

| Type | Method | Scope |
|------|--------|-------|
| **Field-level** | `validate_<fieldname>` | Single field |
| **Object-level** | `validate` | Entire object (cross-field) |
| **Validators** | `validators=[...]` argument on a field | Reusable functions |

---

## Field-Level Validation

Add a method named `validate_` followed by the field name. It receives the field value and must return it (or raise a `ValidationError`):

```python
from rest_framework import serializers

class MovieSerializer(serializers.Serializer):
    name = serializers.CharField()
    ...

    def validate_name(self, value):
        if len(value) < 2:
            raise serializers.ValidationError("Name is too short.")
        return value
```

If the name field has fewer than 2 characters, the API returns:

```json
{"name": ["Name is too short."]}
```

---

## Object-Level Validation

When you need to compare multiple fields, override `validate(self, data)`:

```python
def validate(self, data):
    if data['name'] == data['description']:
        raise serializers.ValidationError(
            "Title and description should be different."
        )
    return data
```

This runs after all individual field validations pass.

---

## Validators (Field Argument)

A validator is a standalone function passed to a field via the `validators` argument. It keeps validation logic reusable and separate:

```python
def name_length(value):
    if len(value) < 2:
        raise serializers.ValidationError("Name is too short.")

class MovieSerializer(serializers.Serializer):
    name = serializers.CharField(validators=[name_length])
    ...
```

Note: when defined as a standalone function (outside the class), do not use `self`.

---

## Comparison: Three Validation Types

```python
class MovieSerializer(serializers.Serializer):
    name        = serializers.CharField(validators=[name_length])  # Validator
    description = serializers.CharField()
    active      = serializers.BooleanField()

    def validate_name(self, value):          # Field-level
        if len(value) < 2:
            raise serializers.ValidationError("Name is too short.")
        return value

    def validate(self, data):                # Object-level
        if data['name'] == data['description']:
            raise serializers.ValidationError("Title and description must differ.")
        return data
```

Use field-level for single-field rules, object-level for cross-field rules, and validators for reusable logic.
