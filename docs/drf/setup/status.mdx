# Status
---
## Why Status Codes Matter

Every HTTP response carries a status code that tells the client what happened. The entire web depends on these codes. DRF provides a `status` module with named constants so you never have to remember raw numbers.

```python
from rest_framework import status
```

---

## Common Status Code Ranges

| Range | Meaning | Example |
|-------|---------|---------|
| `2xx` | Success | `200 OK`, `201 Created`, `204 No Content` |
| `3xx` | Redirection | `301 Moved Permanently`, `307 Temporary Redirect` |
| `4xx` | Client error | `400 Bad Request`, `401 Unauthorized`, `404 Not Found` |
| `5xx` | Server error | `500 Internal Server Error`, `507 Insufficient Storage` |

---

## Most Used Codes

```python
# Success
status.HTTP_200_OK            # Standard GET/PUT response
status.HTTP_201_CREATED       # Object successfully created (POST)
status.HTTP_204_NO_CONTENT    # No body returned (DELETE)

# Client errors
status.HTTP_400_BAD_REQUEST   # Validation error / bad input
status.HTTP_401_UNAUTHORIZED  # Authentication required
status.HTTP_404_NOT_FOUND     # Object not found

# Redirects
status.HTTP_301_MOVED_PERMANENTLY
status.HTTP_307_TEMPORARY_REDIRECT
status.HTTP_308_PERMANENT_REDIRECT
```

---

## Returning Status Codes

Pass a `status` argument to `Response`:

```python
return Response(serializer.data, status=status.HTTP_201_CREATED)
return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
return Response(status=status.HTTP_204_NO_CONTENT)
```

## Handling 404 with Try/Except

If a client requests an ID that does not exist, Django raises a `DoesNotExist` exception. Catch it and return a proper 404:

```python
@api_view(['GET', 'PUT', 'DELETE'])
def movie_detail(request, pk):
    try:
        movie = Movie.objects.get(pk=pk)
    except Movie.DoesNotExist:
        return Response({'error': 'Movie not found'}, status=status.HTTP_404_NOT_FOUND)

    if request.method == 'GET':
        serializer = MovieSerializer(movie)
        return Response(serializer.data)
    ...
```

## Adding Status Codes to All Responses

It is good practice to be explicit about the status code in every response:

```python
if request.method == 'GET':
    ...
    return Response(serializer.data, status=status.HTTP_200_OK)

if request.method == 'POST':
    if serializer.is_valid():
        serializer.save()
        return Response(serializer.data, status=status.HTTP_201_CREATED)
    return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)

if request.method == 'DELETE':
    movie.delete()
    return Response(status=status.HTTP_204_NO_CONTENT)
```
