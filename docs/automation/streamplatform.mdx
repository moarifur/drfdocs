# StreamPlatform
---
## Overview

This lecture covers test cases for the `StreamPlatform` model. It demonstrates how to test admin-only endpoints, validate permission responses (`403 Forbidden`), list resources, and access individual elements using URL kwargs.

The test sequence follows the model dependency order:
```
StreamPlatform → WatchList → Review
```
A WatchList (movie) requires a platform, and a Review requires a movie — so StreamPlatform must be tested first.

---

from rest_framework import status
from rest_framework.test import APITestCase

## `setUp` — User Creation and Authentication

Every test method in the class will run after this setup:

```python
class StreamPlatformTestCase(APITestCase):

    def setUp(self):
        self.user = User.objects.create_user(
            username="example",
            password="Password@123"
        )
        self.token = Token.objects.get(user__username=self.user.username)
        self.client.credentials(HTTP_AUTHORIZATION='Token ' + self.token.key)

        # Manually create a StreamPlatform so tests can access individual items
        self.stream = models.StreamPlatform.objects.create(
            name="Netflix",
            about="A streaming service",
            website="https://www.netflix.com"
        )
```

> The stream platform is created manually (not via API) so tests that access individual elements have a known object to reference.

## Test: Create — Permission Check

Normal users are not allowed to create a StreamPlatform — only admins can. A normal authenticated user should receive `403 Forbidden`.

```python
def test_streamplatform_create(self):
    data = {
        "name": "Netflix",
        "about": "A streaming service",
        "website": "https://www.netflix.com"
    }
    response = self.client.post(reverse('streamplatform-list'), data)
    self.assertEqual(response.status_code, status.HTTP_403_FORBIDDEN)
```

### Permission Response Reference

| User Type | Action | Expected Status |
|---|---|---|
| Unauthenticated | Any request | `401 Unauthorized` |
| Normal user | POST/PUT/DELETE (admin-only) | `403 Forbidden` |
| Admin user | POST/PUT/DELETE | `201 Created` / `200 OK` |
| Any user | GET (read-only) | `200 OK` |

## Test: List — GET All Platforms

```python
def test_streamplatform_list(self):
    response = self.client.get(reverse('streamplatform-list'))
    self.assertEqual(response.status_code, status.HTTP_200_OK)
```

No request body is needed for GET requests. The response should be `200 OK`.

---

## Test: Individual Element — GET by ID

To access a single platform, pass the `pk` (primary key) as a `kwargs` argument inside `reverse()`:

```python
def test_streamplatform_individual(self):
    response = self.client.get(
        reverse('streamplatform-detail', kwargs={'pk': self.stream.pk})
    )
    self.assertEqual(response.status_code, status.HTTP_200_OK)
```

### How `reverse` with `kwargs` Works

```python
# Without kwargs — list endpoint
reverse('streamplatform-list')
# Result: /watch/stream/

# With kwargs — detail endpoint
reverse('streamplatform-detail', kwargs={'pk': 1})
# Result: /watch/stream/1/
```
