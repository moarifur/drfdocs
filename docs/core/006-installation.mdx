2. How to **set up the project** — folder structure, code editor, and extensions
3. How to **send JSON responses** from Django without using DRF (to understand why DRF is needed)

## 1. Check Python Installation

```bash
python -V
```

### Expected Output

```bash
Python 3.x.x
```

> If you see a version number, Python is installed correctly.

> If you see `"python is not recognized"` or `"Python was not found"`, Python is **not** installed.

### Fix

1. Open Microsoft Store
2. Search for **Python**
3. Click **Install**
4. Restart your terminal
5. Run:

```bash
python -V
```

again.

---

## 2. Upgrade pip

```bash
python -m pip install --upgrade pip
```

> `pip` is the package manager used to install Django and other Python libraries.

---

## 3. Virtual Environment

A virtual environment is an **isolated Python environment** for a specific project. It allows different projects to use different package versions without conflicts.

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate It

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / Mac:**
```bash
source venv/bin/activate
```

### Expected Output

```bash
(venv) C:\your-path>
```

> The `(venv)` prefix confirms you are inside the virtual environment.

---

### Verify It Is Empty

```bash
pip freeze
```

A fresh virtual environment will show no packages.

---

## 4. Installing Django

Visit [djangoproject.com](https://www.djangoproject.com) and check the latest stable (LTS) version, then install:

```bash
pip install django
```

Verify installed packages:

```bash
pip freeze
```

You should now see Django and its dependencies listed.

## Project Folder Structure

The recommended structure keeps the virtual environment **outside** the Django project folder:

```
TRF_Project/
├── myvenv/           ← Virtual environment (do NOT mix with project)
└── watchmate/        ← Django project root
    ├── watchmate/    ← Main config directory (settings.py, urls.py)
    ├── watchlist_app/← Your first Django app
    └── manage.py
```

---
## 6. Creating the Django Project

Inside your project folder (with virtual environment activated):

```bash
django-admin startproject watchmate
cd watchmate
```

This creates the following structure:

```
watchmate/              ← Django project root
├── watchmate/          ← Main config folder
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   └── wsgi.py
└── manage.py
```

> The **inner `watchmate/`** folder is your main config directory. The **outer `watchmate/`** is your project root.

---

## 7. Creating a Django App

Django projects are divided into **apps** — each app handles a specific feature.

```bash
# Make sure you're inside the project root (where manage.py is)
python manage.py startapp watchlist_app
```

### App Naming Convention

| App | Purpose |
|---|---|
| `watchlist_app` | Everything related to movies, shows, content |
| `blog_app` | Blog feature (if added later) |
| `user_app` | User management (if added later) |

Each app contains:

```
watchlist_app/
├── admin.py
├── apps.py
├── migrations/
├── models.py
├── tests.py
└── views.py
```

---

## 8. Running the Development Server

```bash
python manage.py runserver
```

Visit `http://127.0.0.1:8000/` to confirm the server is running.
