# ModelViewSets
---

## Overview

`ModelViewSet` is an extension of `ViewSet` that automatically provides all CRUD operations — **list, create, retrieve, update, partial_update, destroy** — with just a `queryset` and `serializer_class`. No need to write any action methods manually.

---

## ViewSet vs. ModelViewSet

| Feature | `ViewSet` | `ModelViewSet` |
|---|---|---|
| Methods provided | None (define your own) | All CRUD automatically |
| Lines needed | ~20+ | **3** |
| Custom logic | Full control | Override individual actions |
| Read-only variant | Manual | `ReadOnlyModelViewSet` |

---

## Full CRUD with ModelViewSet

```python
# views.py
from rest_framework import viewsets
from .models import StreamPlatform
from .serializers import StreamPlatformSerializer

class StreamPlatformVS(viewsets.ModelViewSet):
    queryset = StreamPlatform.objects.all()
    serializer_class = StreamPlatformSerializer
```

Three lines give you the full suite of HTTP operations:

| URL | Method | Action |
|---|---|---|
| `/stream/` | GET | List all platforms |
| `/stream/` | POST | Create a platform |
| `/stream/<pk>/` | GET | Retrieve a platform |
| `/stream/<pk>/` | PUT | Full update |
| `/stream/<pk>/` | PATCH | Partial update |
| `/stream/<pk>/` | DELETE | Delete a platform |

---

## Read-Only with ReadOnlyModelViewSet

When consumers should only be able to *read* data (no create/update/delete):

```python
class StreamPlatformVS(viewsets.ReadOnlyModelViewSet):
    queryset = StreamPlatform.objects.all()
    serializer_class = StreamPlatformSerializer
```

| URL | Method | Action |
|---|---|---|
| `/stream/` | GET | List all |
| `/stream/<pk>/` | GET | Retrieve one |

POST, PUT, PATCH, DELETE are **not available** — the browsable API and Postman will show no such options.

---

## Router Registration (unchanged)

The router configuration is identical for both `ModelViewSet` and `ReadOnlyModelViewSet`:

```python
# urls.py
from django.urls import path, include
from rest_framework.routers import DefaultRouter
from watchlist_app import views

router = DefaultRouter()
router.register('stream', views.StreamPlatformVS, basename='streamplatform')

urlpatterns = [
    path('', include(router.urls)),
]
```

## Adding a Custom Action to ModelViewSet

If you need an action beyond standard CRUD (e.g. manually creating a stream entry with custom validation):

```python
class StreamPlatformVS(viewsets.ModelViewSet):
    queryset = StreamPlatform.objects.all()
    serializer_class = StreamPlatformSerializer

    def create(self, request):
        serializer = StreamPlatformSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        return Response(serializer.errors, status=400)

    def destroy(self, request, pk=None):
        instance = StreamPlatform.objects.get(pk=pk)
        instance.delete()
        return Response(status=204)
```

## Behind the Scenes — ModelViewSet Inheritance

```python
# ModelViewSet inherits from all these mixins:
class ModelViewSet(
    mixins.CreateModelMixin,      # .create()
    mixins.RetrieveModelMixin,    # .retrieve()
    mixins.UpdateModelMixin,      # .update(), .partial_update()
    mixins.DestroyModelMixin,     # .destroy()
    mixins.ListModelMixin,        # .list()
    GenericViewSet
):
    pass
```

Default URL names generated by the router:

| Name | Pattern |
|---|---|
| `streamplatform-list` | `/stream/` |
| `streamplatform-detail` | `/stream/<pk>/` |

## Comparing All ViewSet Types

| Class | Actions Available |
|---|---|
| `ViewSet` | None — define everything manually |
| `ModelViewSet` | list, create, retrieve, update, partial_update, destroy |
| `ReadOnlyModelViewSet` | list, retrieve |

---

## Key Takeaway

> Use `ModelViewSet` when you need full CRUD with minimal code and no special requirements. Use `ReadOnlyModelViewSet` when the resource should be publicly readable but not writable. For anything needing custom `get_queryset`, nested filtering, or `perform_create` overrides, switch to Generic Views.
