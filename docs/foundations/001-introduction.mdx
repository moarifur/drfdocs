# Course overview and curriculum
---

This course is a complete resource for learning and mastering the **Django REST Framework (DRF)** — starting from the basics and advancing step by step. Django REST Framework is one of the most powerful libraries for building flexible and powerful APIs using Python and Django.

## What You Will Build

The course follows a **project-based approach** where you build a fully functional **IMDB Clone API** — similar to the popular movie information website IMDB, supporting:

- Movie storylines
- Ratings and reviews

## Curriculum Highlights

| Section | Topics Covered |
|---|---|
| Foundation | API concepts, REST architecture |
| Core DRF | Serializers, Function-Based Views, Class-Based Views |
| Intermediate | Generic Views, Mixins, ViewSets |
| Advanced | Permissions, Authentication (Token & JWT) |
| Features | Throttling, Filtering, Searching, Ordering |
| Final | Pagination, Automated Testing |

## Prerequisites

- Basic knowledge of **Python**
- Basic knowledge of **Django**

## What You Get

- High-quality video lectures
- Complete source code for the entire project
- Resources in the form of links and PDFs
