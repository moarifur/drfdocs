# Setup
---
## Goal of This Section

This section covers:
1. A **Django refresher** to lay the foundation for the project
2. How to **set up the project** — folder structure, code editor, and extensions
3. How to **send JSON responses** from Django without using DRF (to understand why DRF is needed)

---

## 1. Check Python Installation

```bash
python -V
```

### Expected Output

```bash
Python 3.x.x
```

> If you see a version number, Python is installed correctly.

> If you see `"python is not recognized"` or `"Python was not found"`, Python is **not** installed.

### Fix

1. Open Microsoft Store
2. Search for **Python**
3. Click **Install**
4. Restart your terminal
5. Run:

```bash
python -V
```

again.

---

## 2. Upgrade pip

```bash
python -m pip install --upgrade pip
```

> `pip` is the package manager used to install Django and other Python libraries.

---

## 3. Virtual Environment

A virtual environment is an **isolated Python environment** for a specific project. It allows different projects to use different package versions without conflicts.

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate It

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / Mac:**
```bash
source venv/bin/activate
```

### Expected Output

```bash
(venv) C:\your-path>
```

> The `(venv)` prefix confirms you are inside the virtual environment.

---

### Verify It Is Empty

```bash
pip freeze
```

A fresh virtual environment will show no packages.

---

## 4. Installing Django

Visit [djangoproject.com](https://www.djangoproject.com) and check the latest stable (LTS) version, then install:

```bash
pip install django
```

Verify installed packages:

```bash
pip freeze
```

You should now see Django and its dependencies listed.

---

## 5. Code Editor

It is recommended to use **Visual Studio Code**. Install the following extensions:

- **Python** — for IntelliSense, linting, and Django support
- **Tabnine** — for AI-powered autocomplete (useful once you have some Django experience)

After installing extensions, reload VS Code to activate them.

## Project Folder Structure

The recommended structure keeps the virtual environment **outside** the Django project folder:

```
TRF_Project/
├── myvenv/           ← Virtual environment (do NOT mix with project)
└── watchmate/        ← Django project root
    ├── watchmate/    ← Main config directory (settings.py, urls.py)
    ├── watchlist_app/← Your first Django app
    └── manage.py
```
