# Models
---
## Goal

In this section you will:
1. Register the app in `INSTALLED_APPS`
2. Run initial migrations
3. Create a superuser
4. Define a `Movie` model
5. Create and apply model migrations
6. Register the model in the admin panel

---

## Run Initial Migrations

Django ships with built-in migrations for its admin panel, authentication system, and more. Apply them first:

```bash
python manage.py migrate
```

---

## Create a Superuser

```bash
python manage.py createsuperuser
```

Provide a username, email (optional), and password. Use a strong password in production. For development, any password works (confirm bypass if prompted).

---

## Define the Movie Model

Open `watchlist_app/models.py` and define your model:

```python
from django.db import models

class Movie(models.Model):
    name = models.CharField(max_length=50)
    description = models.CharField(max_length=200)
    active = models.BooleanField(default=True)

    def __str__(self):
        return self.name
```

**Field breakdown:**
- `name` — movie title, up to 50 characters
- `description` — short summary, up to 200 characters
- `active` — whether the movie is published; defaults to `True`
- `__str__` — returns the movie name when an object is printed or referenced

---

## Create and Apply Migrations

### Step 1 — Generate migration files

```bash
python manage.py makemigrations
```

This converts your model into SQL queries stored in `watchlist_app/migrations/`.

### Step 2 — Apply migrations to the database

```bash
python manage.py migrate
```

Django uses SQLite by default, which is fine for development. For production, use PostgreSQL or MySQL.

---

## Register in Admin

Open `watchlist_app/admin.py`:

```python
from django.contrib import admin
from watchlist_app.models import Movie

admin.site.register(Movie)
```

---

## Test in Admin Panel

Start the server:

```bash
python manage.py runserver
```

Visit `http://127.0.0.1:8000/admin/`, log in with your superuser credentials, and you should see **Watchlist App → Movies** in the panel.

Add a few sample movies (e.g., "Python vs Java", "JavaScript The Movie") to use in the next lecture.
